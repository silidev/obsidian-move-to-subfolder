## Usage
Adds the command "Move the current note into a new subfolder". This command creates a folder named after the current note in the same directory as the current note. The current note is then moved into this folder. Then, the rename dialog for the folder opens.
Also helpful to organize into folders is my plugin [Move to linking file](https://community.obsidian.md/plugins/move-to-linking-file).
## Installation
Install it from https://community.obsidian.md/plugins/move-to-subfolder.
Consider assigning it to a hotkey (I use Ctrl+F3).
